### 🧮 Python Calculator

My first Python project.

It started as a simple command-line calculator and gradually evolved into a small desktop application with:

* Tkinter GUI
* Safe AST-based expression evaluation
* Mathematical functions and constants
* Degree (`°`) angle notation
* Persistent calculation history
* Easter eggs
* Automated tests with pytest
* Windows executable packaging with PyInstaller
